# Roadmap Pengembangan

## Tahap 1 — Perencanaan
- [x] Mengidentifikasi sumber wawancara yang digunakan.
- [x] Menyusun kebutuhan awal produk.
- [x] Menyusun rancangan UI/UX.
- [x] Menentukan fitur MVP.
- [x] Menyusun rencana teknologi dan cloud.
- [x] Menyusun rencana pengujian.

## Tahap 2 — Validasi rancangan
- [ ] Memeriksa kembali materi dan tujuan pembelajaran.
- [ ] Meminta masukan dosen/guru jika memungkinkan.
- [ ] Meninjau rancangan layar smartphone.
- [ ] Menentukan gaya visual final.

## Tahap 3 — Implementasi
- [ ] Membuat struktur folder proyek.
- [ ] Membuat halaman beranda.
- [ ] Membuat halaman materi.
- [ ] Membuat contoh soal bertahap.
- [ ] Membuat latihan interaktif.
- [ ] Membuat umpan balik dan hasil latihan.

## Tahap 4 — Pengujian
- [ ] Menguji perhitungan median data ganjil dan genap.
- [ ] Menguji input kosong dan input tidak valid.
- [ ] Menguji navigasi.
- [ ] Menguji tampilan pada Android.
- [ ] Memperbaiki bug yang ditemukan.

## Tahap 5 — Publikasi
- [ ] Memilih layanan hosting.
- [ ] Melakukan deployment.
- [ ] Menguji URL publik pada Android.
- [ ] Menyusun dokumentasi penggunaan dan hasil pengujian.

## Catatan

Checklist implementasi, pengujian, dan publikasi masih belum dikerjakan. Checklist hanya ditandai selesai setelah aktivitasnya benar-benar dilakukan.
