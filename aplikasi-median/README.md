## Deskripsi Aplikasi

Aplikasi Pembelajaran Statistika: Median (Nilai Tengah) merupakan media pembelajaran berbasis web yang dirancang untuk membantu peserta didik SMP memahami materi median dalam statistika.

Aplikasi ini menyediakan materi pembelajaran, contoh penyelesaian soal secara bertahap, serta latihan interaktif untuk membantu peserta didik memahami cara menentukan median dari sekumpulan data.

## Tujuan Aplikasi

1. Membantu peserta didik memahami pengertian median.
2. Membantu peserta didik mengurutkan data dari nilai terkecil hingga terbesar.
3. Membantu peserta didik menentukan median pada data berjumlah ganjil dan genap.
4. Memberikan kesempatan kepada peserta didik untuk berlatih secara mandiri.

## Fitur Aplikasi

1. **Beranda:** Menampilkan pengenalan aplikasi dan tujuan pembelajaran.
2. **Materi:** Menjelaskan pengertian median, langkah menentukan median, serta median pada data ganjil dan genap.
3. **Contoh Pembelajaran:** Menampilkan contoh soal dan penyelesaian secara bertahap.
4. **Latihan Soal:** Menyediakan lima soal latihan interaktif.
5. **Pemeriksaan Jawaban:** Memberikan informasi benar atau salah beserta pembahasannya.
6. **Hasil Latihan:** Menampilkan jumlah jawaban benar dan skor.
